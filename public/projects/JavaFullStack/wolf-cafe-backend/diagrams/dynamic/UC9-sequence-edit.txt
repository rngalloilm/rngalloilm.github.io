title Edit Existing System Information

actor Admin
participant HomePage
participant StaffPage
participant AuthController
participant UserService
participant UserRepository

Admin -> HomePage: Navigate to "Staff" page
HomePage -> StaffPage: Load Staff List
Admin -> StaffPage: Select Staff member to edit
StaffPage -> AuthController: Validate Admin Role
AuthController -> UserService: loadUserByUsername(String email)
UserService -> UserRepository: findByUsername(String username)
UserRepository --> UserService: Optional<User>
UserService --> AuthController: User
AuthController --> StaffPage: Admin Role Validated

Admin -> StaffPage: Modify Staff Information
StaffPage -> UserRepository: save(User)
UserRepository --> StaffPage: User (Updated)

StaffPage -> Admin: Display updated Staff Information
